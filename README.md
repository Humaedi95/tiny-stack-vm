A tiny stack virtual machine for the make.fun bounty
tiny-stack-vm-01-run-20261122. In one run it answers all 40 instances:
it reads `/input/<id>/program.bin` and `/input/<id>/input.bin`, runs the
bytecode, and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt`.

Run: `node main.ts`
